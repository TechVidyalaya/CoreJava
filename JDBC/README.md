# JDBC (Java Database Connectivity)

## 📖 Module Overview

**JDBC (Java Database Connectivity)** is the standard Java API for connecting and interacting with relational databases. It allows Java applications to execute SQL queries, retrieve data, manage transactions, and build database-driven applications.

JDBC is the foundation for technologies like **Hibernate**, **Spring Data JPA**, and many enterprise Java applications.
